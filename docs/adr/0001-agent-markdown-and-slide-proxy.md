# Агентское представление конспектов и проксирование слайдов через платформу

ИИ-агенты (как локальные CLI-инструменты, так и облачные веб-фетчеры) теряют структуру на обвязке SSR-HTML «Читального зала», раздувают контекст длинными временными S3 presigned-ссылками и ломаются при их протухании через 24 часа или блокировке стороннего S3-домена. Мы отдаём каноническое агентское представление в `text/markdown` из `structure.json` как по явному маршруту `/read/{id}.md` (и каталогам `/hub.md`, `/llms.txt`), так и на основном `/read/{id}` через согласование `Accept: text/markdown` и распознавание агентских `User-Agent` (с `Vary: Accept, User-Agent`), а изображения слайдов стримим напрямую через платформу по стабильным URL `/read/{id}/slides/{n}` с проверкой прав на каждый запрос (в отступление от общего правила «весь контент — только presigned S3», которое сохраняется для тяжёлых медиафрагментов в браузере).
