# Handoff: Просмотр конспекта (Notes Viewer) + дизайн-система сервиса

## Overview
Сервис принимает аудио/видео лекции (+ опционально слайды) и генерирует структурированный конспект в Markdown: материал разбит по темам и подтемам, к каждой подтеме привязан свой фрагмент медиа (тайм-код), текст и относящиеся к нему слайды. В начале — кликабельное оглавление.

Этот пакет описывает **страницу просмотра конспекта** (главный экран) и задаёт **воспроизводимую дизайн-систему «Читальный зал»** для всех остальных страниц сервиса (загрузка, обработка, список, ошибки).

## About the Design Files
Файлы в `prototypes/` — это **дизайн-референс, сделанный в HTML** (прототип, показывающий внешний вид и поведение), **а не продакшн-код для копирования**. Задача — **воссоздать этот дизайн в вашей кодовой базе** на её привычном стеке (React/Vue/Svelte/SwiftUI/нативе), используя её компоненты и паттерны. Если кодовой базы ещё нет — выберите подходящий фреймворк (рекомендация: React + Vite, либо Next.js) и реализуйте дизайн там.

`Конспект.dc.html` — это «Design Component»: самодостаточный HTML-файл, открывается в браузере напрямую. Внутри — `<style>` (вся визуалка) и `<script>` с классом `Component` (вся логика в `componentDidMount`, чистый ванильный JS, без фреймворков). Читайте его как референс разметки/стилей/поведения; переносите в идиомы своего стека.

## Fidelity
**High-fidelity.** Финальные цвета, типографика, отступы и интеракции. Воссоздавайте UI пиксель-в-пиксель средствами вашей библиотеки компонентов. Все точные значения — в `tokens.css` и `STYLE_GUIDE.md`.

## Screens / Views

### 1. Notes Viewer (страница просмотра конспекта) — реализована в прототипе
**Purpose.** Пользователь читает конспект, прыгает по оглавлению, слушает/смотрит привязанные фрагменты, разворачивает отступления, ищет по тексту, экспортирует в MD, переключает тему.

**Layout.**
- Sticky-шапка (высота 58px) во всю ширину; внутр. контейнер `max-width:1180px`, паддинг 0 22px. Под ней — полоса прогресса чтения (2px).
- Ниже — двухколоночник `max-width:1180px`:
  - **Сайдбар** слева: `flex:0 0 312px`, `position:sticky; top:58px; height:calc(100vh - 58px)`, своя прокрутка, правая граница `--border`, паддинг `30px 26px 60px`.
  - **Контент** справа: `flex:1`, центрируется; внутр. колонка `max-width:768px`, паддинг `60px 48px 140px`.
- ≤980px: сайдбар → выезжающая слева панель (320px, transform), бургер в шапке, затемнение-overlay. ≤520px: компактная шапка, паддинги меньше.

**Components.**
- **Шапка**: марка (квадрат 24px `--accent` с кольцом) + название источника (sans 13.5, `--text-2`, ellipsis); справа — иконка поиска, кнопка «Экспорт MD», иконка темы. Подпись кнопки скрывается ≤520px.
- **Полоса прогресса**: высота 2px, заполнение `--accent`, ширина = % прокрутки.
- **Строка поиска**: разворачивается под шапкой (max-height transition); поле `--surface`, счётчик «N / M», кнопки назад/вперёд/закрыть.
- **Сайдбар**: карточка источника (лейбл «ИСТОЧНИК» + название serif 16/600 + бейдж «Видео» + чипы «1:12:30», «17.06.2026»); блок «Прогресс чтения» (лейбл + % + дорожка 4px); оглавление — 5 разделов, в каждом вложенные подтемы; активный пункт подсвечен `--accent` + левая граница (scroll-spy).
- **Шапка документа**: кикер «КОНСПЕКТ ЛЕКЦИИ» (uppercase `--accent`), H1 (serif 43/600), лид (serif 20 italic `--text-2`), мета-строка над `--border` (разделы/подтемы, источник, дата сборки).
- **Лента времени**: вертикальная линия `--rail` вдоль секций, узлы у заголовков разделов (заполненный 15px) и подтем (полый 9px). См. `STYLE_GUIDE.md §4`.
- **Раздел**: заголовок = номер (sans `--accent`) + название (serif 28/600), нижняя `--border-2`.
- **Подтема**: номер + название (serif 21/600); далее плеер фрагмента, абзацы (serif 19/1.78), при наличии — слайды и/или callout.
- **Медиаплеер**, **Слайд + лайтбокс**, **Callout (`<details>`)**, **Тост** — точные спеки в `STYLE_GUIDE.md §5`.
- **Футер**: марка + строка «Конспект сгенерирован автоматически · дата». Без кнопок (экспорт только в шапке).

Точные размеры/цвета/шрифты всех компонентов — в `STYLE_GUIDE.md` и `tokens.css`.

## Interactions & Behavior
- **Scroll-spy + прогресс.** На скролл (через `requestAnimationFrame`-throttle): обновляется ширина полосы прогресса и блока «Прогресс чтения» (% от прокрутки документа); активной становится последняя подтема, чей `top ≤ 132px`; соответствующий пункт оглавления получает активный стиль.
- **Навигация по оглавлению.** Клик по пункту — плавный скролл (`window.scrollTo`, **не** `scrollIntoView`) к подтеме с офсетом −72px; на мобайле закрывает панель.
- **Плееры (прототип — симуляция).** Клик play: ставит на паузу другой играющий (одновременно играет один), запускает интервал, увеличивает текущее время, двигает заполнение/ручку. Клик по дорожке — перемотка. Позиция сохраняется в `localStorage['notes_players']`. **В проде**: заменить на реальный `<audio>`/`<video>` с привязкой к `currentTime`/`seek`, фрагмент = `[start,end]` исходного медиа.
- **Поиск.** Дебаунс 180ms; обход текстовых узлов колонки (TreeWalker), оборачивание совпадений в `<mark>`; счётчик, переходы next/prev (Enter / Shift+Enter), `Esc`/закрытие — снять подсветку.
- **Экспорт MD.** Кнопка «Экспорт MD» собирает Markdown из DOM (заголовки, тайм-коды фрагментов, абзацы, слайды как `![]()`, callout как цитаты) и скачивает `.md`-файл; показывает тост. **В проде**: брать готовый MD с бэкенда, а не реконструировать из DOM.
- **Тема.** Тумблер переключает `data-theme` на корне и сохраняет в `localStorage['notes_theme']`.
- **Лайтбокс.** Клик по слайду открывает увеличенную копию на затемнении; клик — закрыть.
- **Callout.** Нативный `<details>`: клик по summary — свернуть/развернуть, шеврон поворачивается.

**Переходы/моторика.** Интерактив — 0.14–0.22s ease. Полосы прогресса — `width .12s linear`. Шеврон callout — `transform .22s`. ⚠️ Видимость контента **не** завязывать на анимацию (см. `STYLE_GUIDE.md §8`).

## State Management
- `theme: 'light' | 'dark'` — персист (localStorage / профиль).
- `activeSubtopicId` — производное от скролла (scroll-spy).
- `readingProgressPct` — производное от скролла.
- `players: { [fragmentId]: positionSeconds }` — персист; в проде синхронизировать с медиаэлементом.
- `search: { query, matches[], currentIndex }`.
- `searchOpen`, `navDrawerOpen` (мобайл), `lightbox: { openSlideId | null }`.
- **Данные конспекта** (с бэкенда): `{ source: {title, type, duration, date}, sections: [{ num, title, subtopics: [{ num, title, media:{kind,start,end}, blocks:[ {type:'paragraph',html} | {type:'slide', n, title, bullets[]} | {type:'callout', label, text} ] }] }] }`. Разметка прототипа 1:1 ложится на эту модель.

## Как загрузить это в Claude Code

1. **Скачайте zip** этого пакета (кнопка загрузки в чате) и распакуйте.
2. Положите папку **в корень вашего репозитория**, например `design/notes_viewer/`, и закоммитьте — так Claude Code видит файлы как часть проекта.
3. Откройте репозиторий в терминале и запустите **`claude`** (Claude Code). Команды-подсказки:
   - Дайте контекст: «Прочитай `design/notes_viewer/README.md`, `STYLE_GUIDE.md` и `tokens.css`. Открой `prototypes/Конспект.dc.html` в браузере, чтобы увидеть целевой дизайн.»
   - Затем задача: **«Воссоздай страницу просмотра конспекта в нашем стеке (<укажите: React/Vue/...>), используя наши существующие компоненты. Тема и токены — из tokens.css. Это дизайн-референс, не копируй HTML дословно — перенеси в наши паттерны.»**
4. **Просмотр прототипа**: `Конспект.dc.html` открывается двойным кликом в браузере (нужен интернет для шрифтов). Можно также сказать Claude Code: «запусти локальный сервер и открой прототип», если хотите смотреть его рядом.
5. **Токены первым делом.** Попросите сначала перенести `tokens.css` в вашу систему тем (CSS-переменные / Tailwind theme / styled-system), затем строить компоненты поверх — так тёмная тема и консистентность получатся бесплатно.
6. **Порядок реализации (рекомендация):** токены → каркас (шапка + раскладка + сайдбар) → лента времени и типографика контента → плеер → слайд+лайтбокс → callout → поиск → scroll-spy/прогресс → тема → адаптив. Реальное медиа и MD с бэкенда подключать вместо симуляций (см. Interactions).

> Примечание: `.dc.html` — формат для прототипирования. В вашем проекте он нужен только как визуальный эталон; не тащите его в продакшн-бандл.
