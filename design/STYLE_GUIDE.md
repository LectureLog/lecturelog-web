# Style Guide — «Читальный зал»

Воспроизводимая дизайн-система для всех страниц сервиса (просмотр конспекта, загрузка, обработка, список конспектов, ошибки/пустые состояния). Цель — единый визуальный язык: спокойная среда для длинного чтения, без «AI-шных» приёмов.

Все токены — в `tokens.css` (подключить на `:root`). Здесь — как ими пользоваться.

---

## 1. Принципы

1. **Почти монохром + один акцент.** Палитра — нейтральная бумага и тёмные чернила. Цвет — только вечнозелёный `--accent`, и только для действий/активных состояний/акцентов. Никаких вторых-третьих ярких цветов, никаких градиентов, никакого неона.
2. **Серив ради чтения.** Весь смысловой контент — `Source Serif 4` (тёплый, низкоконтрастный, отлично читается, есть кириллица). `Onest` (sans) — только для интерфейсной мелочи: шапка, оглавление, лейблы, тайм-коды, кнопки, мета.
3. **Hairline, а не тени.** Разделение — тонкими границами `--border`. Тени мягкие и редкие (`--shadow`), только у «приподнятых» карточек.
4. **Воздух и мера колонки.** Текст для чтения — ширина строки ≈ 65ch, межстрочный 1.78. Не растягивать абзацы на всю ширину.
5. **Спокойная моторика.** Переходы 0.14–0.22s. Без эффектных въездов, от которых зависит видимость контента (см. §8).

---

## 2. Цвет

Используйте **только** переменные из `tokens.css`. Не вводите новые цвета — при нехватке оттенка берите соседнюю переменную или микс существующих.

| Назначение | Токен |
|---|---|
| Фон страницы | `--bg` |
| Шапка, панель | `--bg-2` |
| Карточки/плееры/слайды | `--surface` |
| Вложенные поверхности (дорожки) | `--surface-2` |
| Основной текст | `--ink` |
| Вторичный / подписи | `--text-2` |
| Лейблы / мета / плейсхолдеры | `--text-3` |
| Границы | `--border`, `--border-2` |
| Действие / активное / ссылки | `--accent` (hover `--accent-2`) |
| Фон бейджей | `--accent-soft` |

Тёмная тема — те же переменные, переопределённые под `[data-theme="dark"]`. Никаких отдельных «тёмных» цветов в компонентах — пишите всё через переменные, и тема работает сама.

## 4. Сетка и раскладка

- **Шапка** (sticky, высота 58): фон `--bg-2` с `backdrop-filter: blur(12px)`, нижняя `--border`. Внутр. контейнер `max-width:1180px`, отступ 22px. Слева — марка + название источника, справа — действия. Под шапкой тонкая полоса прогресса чтения (2px, `--accent`).
- **Двухколоночная раскладка** (`max-width:1180px`): слева sticky-сайдбар `312px` (оглавление), справа — контент.
- **Колонка контента**: центрируется, `max-width:768px`, паддинг `60px 48px 140px`.
- **Брейкпоинты**: `980px` — сайдбар превращается в выезжающую панель (бургер в шапке + затемнение `--overlay`); `520px` — компактная шапка (прячется подпись кнопки), уменьшенные паддинги.

### «Лента времени» (фирменная деталь)
Вертикальная линия 1.5px цвета `--rail` идёт вдоль колонки контента; у заголовка раздела — заполненный узел `--accent` (15px), у подтемы — полый узел (9px, обводка `--accent`). Реализация: контейнер секций `position:relative; padding-left:40px`, линия — `::before` (`left:11px`), узлы — `::before` на `.sec-head` / `.sub-head` со сдвигом в левый жёлоб. Семантически узлы = тайм-коды фрагментов → видна хронология лекции.

## 5. Компоненты

Все радиусы — из `tokens.css`. Все цвета — переменные.

### Кнопки
- **Вторичная** (`.btn`): высота 37, паддинг 0 15, фон `--surface`, граница `--border-2`, радиус `--r-btn`, текст `--ink`, sans 13/500. Hover: граница и текст → `--accent`.
- **Иконочная** (`.icon-btn`): 37×37, прозрачная, иконка `--text-2`. Hover: фон `--surface-2`, иконка `--ink`. Иконки — `stroke` 2px, размер 18.
- **Основное действие** (по необходимости): фон `--accent`, текст `--bg`. Hover `--accent-2`. Без теней и градиентов.

### Карточка / поверхность
Фон `--surface`, граница `--border`, радиус `--r-card`, тень `--shadow` (только если карточка «приподнята»). Внутр. паддинг 13–17px.

### Бейдж / пилюля
Фон `--accent-soft`, текст `--accent`, радиус `--r-pill`, sans 11/600, паддинг 3×9. Иконка 11px.

### Медиаплеер (фрагмент)
Карточка `--surface`. Верхняя строка: бейдж «Видео»/«Аудио» + диапазон тайм-кодов (`12:10 – 18:45`, sans tabular) + длительность справа (`--text-3`). Нижняя строка: круглая кнопка play 40px (`--accent`, иконка `--bg`) + дорожка (высота 6, фон `--surface-2`, граница `--border`, заполнение `--accent`, ручка 13px белая с обводкой `--accent`) + текущее время справа. Поведение — см. README §Interactions.

### Слайд (вставка в текст)
`aspect-ratio:16/10`, фон `--surface`, граница `--border-2`, радиус `--r-slide`, паддинг 26×30. Сверху-справа тег «Слайд NN» (`--text-3`, tabular). Внутри: акцентная черта 32×3 `--accent`, заголовок (serif 20/600), список с круглыми маркерами `--accent` (sans 13.5). Hover: граница → `--accent`, курсор zoom-in. Клик → лайтбокс (увеличенная копия по центру на затемнении, клик — закрыть).
Подпись под слайдом (`.figcap`): sans 12.5, `--text-3`, номер жирный `--text-2`.

### Callout (сворачиваемый «Отступление от темы»)
Нативный `<details>`: карточка `--surface`/`--border`/`--r-card`. `<summary>` — строка-заголовок: иконка-лид 15px + UPPERCASE-лейбл sans 11/600 `--accent` + шеврон справа (`--text-3`), без маркера списка. В открытом состоянии у summary появляется нижняя `--border`, шеврон поворачивается на 180° (transition .22s). Тело: текст serif 17 *italic* `--ink`.

### Оглавление (сайдбар)
Карточка источника (лейбл «ИСТОЧНИК» + название serif + бейдж типа + мета). Блок «Прогресс чтения» (лейбл + % + дорожка 4px). Дерево: разделы (номер tabular + название sans 13/600 `--text-2`), вложенные пункты — список с левой границей `--border`; пункт `--text-2`, hover `--ink`. **Активный пункт**: текст `--accent`, weight 600, левая граница 2px `--accent` (scroll-spy).

### Подсветка поиска
`<mark>`: фон `--mark`, текст `--ink`. Активное совпадение `mark.cur`: фон `--mark-cur` + `box-shadow:0 0 0 2px var(--mark-cur)`.

### Тост
Низ-центр, фон `--ink`, текст `--bg`, радиус 11, sans 13.5/500, иконка-галочка. Появление через `opacity`+`translateY` (transition), авто-скрытие ~2.2s.

## 6. Иконки

Линейные, `stroke-width:2`, `fill:none`, `viewBox 0 0 24 24`, цвет `currentColor`. Размер: 18 (шапка), 15 (кнопки/лейблы), 11 (бейджи). Если в кодовой базе есть icon-set (Lucide/Feather/Phosphor) — использовать его в том же линейном стиле. Иконка play — единственная заливная (`fill:currentColor`).

## 7. Состояния для НОВЫХ страниц сервиса

Держите тот же каркас (sticky-шапка + центрированная колонка / двухколоночник) и те же токены.

- **Загрузка (upload).** Центрированная колонка. Крупная дроп-зона: пунктир `--border-2`, радиус `--r-card`, фон `--surface`, иконка + текст serif. Активное перетаскивание → граница `--accent`, фон `--accent-soft`. Опции (извлекать слайды из видео и т.п.) — переключатели в стиле §5. Кнопка запуска — основное действие.
- **Обработка (processing).** Спокойный прогресс по этапам (транскрипт → сегментация по темам → сборка конспекта). Шаги вертикальным списком на «ленте времени» (переиспользуйте узлы из §4): готовый — заполненный узел `--accent`, текущий — пульсирующий, будущий — полый. Прогресс-дорожка как в §5. Без спиннеров-каруселей; текст-статусы serif.
- **Список конспектов (library).** Сетка/список карточек: название (serif 16/600), мета (тип, длительность, дата — sans `--text-2`), бейдж статуса. Hover карточки — граница `--accent`. Та же шапка.
- **Пусто / ошибка.** Центрированный блок: иконка `--text-3`, заголовок serif, поясняющий текст `--text-2`, одно основное действие. Спокойно, без иллюстративного «слопа».

## 8. Технические правила (важно)

- **Никогда не завязывайте видимость контента на анимацию появления.** Базовое состояние элементов — видимое (`opacity:1`). Въезды — только как прогрессивное улучшение (через `@media (prefers-reduced-motion: no-preference)` и/или класс, добавляемый после загрузки), которое не может оставить контент невидимым. (В прототипе анимация шапки была убрана именно по этой причине.)
- **Тема** — атрибут `data-theme` на корне + переменные. Не хардкодьте цвета в компонентах.
- **Сохраняйте состояние** позиций плееров и выбор темы (localStorage или профиль пользователя). В проде позицию плеера привязывать к реальному `currentTime` медиаэлемента.
- **tabular-nums** для всего числового (время, проценты, даты).
- **Доступность**: фокус-стили на интерактиве, `aria-label` на иконочных кнопках, контраст текста ≥ 4.5:1 (палитра это обеспечивает), хит-таргеты ≥ 40px.
